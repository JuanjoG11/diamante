# Club Deportivo El Diamante — Ejercicios Coordinativos

## Cómo usar

1. Guarda el logo del club como `logo.png` en esta misma carpeta (`diamante/`).
2. Abre `index.html` en tu navegador.
3. ¡Listo! La página ya funciona.

## Estructura
```
diamante/
  index.html   ← La página web completa
  logo.png     ← Pon aquí el logo del club (el círculo con CDD Diamante)
  README.md    ← Este archivo
```

## Para agregar videos de Dieguito
En el `index.html`, busca cada `<div class="video-placeholder">` y reemplázalo por:
```html
<iframe src="https://www.youtube.com/embed/AQUI_EL_ID" allowfullscreen></iframe>
```

## Colores usados
- Naranja: `#E8541A`
- Azul marino: `#1A2B4A`
- Fondo oscuro: `#0F1E35`
- Blanco: `#FFFFFF`
